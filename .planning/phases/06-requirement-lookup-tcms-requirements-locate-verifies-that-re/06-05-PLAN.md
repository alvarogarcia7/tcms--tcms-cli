<objective>
Add `tcms requirements export-ids [--requirements <FILE>] [--output <FILE>] [--input export.json] [--as user]`
to the `tcms` binary: read the product requirements file (D-11), check every ID with the batch lookup
of `locate` (D-12), write the valid IDs as JSON in the same shape and list the invalid ones on stderr,
with exit codes 0/1/2 (D-13, following D-06).

Purpose: a product can filter its requirements list down to the IDs that really exist in Jira or the
StrictDoc export (LOOK-06, LOOK-07).
Output: new module `crates/tcms/src/export_ids.rs`; a shared `lookup` function extracted from
`locate.rs` (no change to `locate` behaviour); `ExportIds` variant in reqcmd.rs; `mod export_ids;` in
main.rs; binary tests in `crates/tcms/tests/requirements_export_ids_cli.rs`.
</objective>
