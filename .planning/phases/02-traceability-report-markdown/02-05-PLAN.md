<objective>

Purpose: OUT-04 says a missing header value is written as "not recorded". A blank string in YAML is a missing value in practice, so it must show the same text.
Output: one shared blank-value rule, its unit tests, and a CLI test that runs the real binary with `baseline_id: ""`.

This plan does not change plans 02-01 to 02-04 or their summaries. It touches only the four files listed above. TRC-03 stays deferred to Phase 7 and is not claimed here.
