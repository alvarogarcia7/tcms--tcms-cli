Libraries available to wire in:
- `testcase_reporting::model::{build_model, ReportInputs, RequirementDocuments}` (02-02), `testcase_reporting::render_markdown::render_markdown` (02-03)
- `testcase_reporting::legacy::load_test_cases_strict(dir: &Path) -> Result<Vec<TestCase>>`
- `requirement_import::strictdoc::export_items(json: &str) -> Result<Vec<ExportItem { uid, level, title, status, path }>>` (already used by main.rs through `requirement_import::strictdoc`)
- chrono is a workspace dependency (check test-executor/Cargo.toml; add `chrono = { workspace = true }` only if missing).
