<objective>
Make `tcms vv metrics` read the per-product V&V settings that Verdict keeps (TCMS-47.2): the gate
threshold and the flaky threshold from `<DATA_ROOT>/vv-config.yaml`, and a new stability window.

Purpose: a CI job that runs the CLI directly must use the same gate and window as Verdict. Today it
cannot see the file, and the window is not configurable at all.
Output: config reader with source labels, `--stability-window` flag, `parameters` block in the output,
binary tests, docs.

Depends on 09-01 because the config and window tests run end to end on combined run records.
Test-first: Task 1 writes the failing tests; Task 2 implements; Task 3 is a checkpoint for the missing
schema and the naming decision; Task 4 documents.
</objective>
