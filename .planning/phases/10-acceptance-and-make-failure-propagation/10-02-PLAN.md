<objective>
Make `make test` and `make coverage-e2e` fail when a test step reports failure. Covers TCMS-46
acceptance criteria 1, 2 and 3.

Root causes found on `dev` (to confirm in Task 1):
1. The affected-crate branch of `test-e2e` in `Makefile` chains `${MAKE} test-verifier-edge-cases;`
   and `./scripts/run_verifier_and_generate_reports.sh;` with `;`. Only the last command's status reaches
   make (`${MAKE} validate-output-schemas`), so a failing verifier step is swallowed. The no-changes branch
   does the same to `check_environment.sh`.
2. The per-script loop does `bash "$$test_script" || exit 1` (correct) but skips a listed script that is
   missing (`if [ -f "$$test_script" ]`).
3. `scripts/lib/logger.sh` `fail()` only prints. A script that calls `fail` and then falls through with
   exit 0 is green. Scripts reached from the Make targets need `exit 1` on failure.

Decisions: D-46-1 (exit codes are the mechanism; no grep of output as the primary check), D-46-2
(warning fixed at cause or fails the run), D-46-3 (green stays green; no test weakened).

Purpose: a green `make` run must mean the suite passed.
Output: runner script, RED-first runner tests, Makefile recipe fix, exit-code fixes in the scripts the
investigation finds.
</objective>
