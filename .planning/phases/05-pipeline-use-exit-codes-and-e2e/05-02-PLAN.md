<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| command line -> exit status | CI jobs gate releases on the exit code |
| run and matrix files -> report and exit status | User data decides output and code |
| `--output` -> filesystem | The file is created or truncated at a user-chosen path |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-03 | Repudiation | exit 0 when failures exist and the user expected a gate | accept | The flag is opt-in as CLI-02 specifies; docs state that without `--fail-on-gaps` the exit is 0 (plan 05-03) |
| T-05-04 | Tampering | exit 2 discards or truncates the report | mitigate | Write and flush happen before the only `exit(2)`; tests compare the bytes of the exit-2 run with the exit-0 run |
| T-05-05 | Tampering | an error masked as exit 2, or exit 2 after a partial write | mitigate | Errors return before any write (exit 1); `errors_win_over_the_flag` asserts exit 1 and no file for each error class |
| T-05-06 | Spoofing | clap usage error taken for a gap result | mitigate | Usage errors of `report` map to 1; `usage_errors_exit_1` asserts it; other commands unchanged and asserted |
| T-05-07 | Information disclosure | stderr summary line | accept | It holds two counts only |
| T-05-SC | Tampering | package installs | accept | No new dependency (serde_json already a dependency after Phase 4) |
</threat_model>
