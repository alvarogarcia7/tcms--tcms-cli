    D. errors win (exit 1 even with the flag, and no output file is created when `-o` is used): invalid matrix; two run files sharing a run_id; a broken YAML run file; `--generated-at yesterday`; `-o` into a directory that does not exist; `--kind summary --format json`; a JSON schema violation, using `cp -R schemas` into the temp directory, overwriting its `tcms/report.schema.v1.json` with `{"type":"object","required":["nonexistent_field"]}` through `printf`, running with `cd` into the temp directory in a subshell and absolute input paths.

    F. other subcommands keep clap's code (D-03): `test-executor generate` without argument exits 2; an unknown subcommand exits 2.
    G. closed set: every code recorded by `run_report` during the run is 0, 1 or 2; the script keeps the codes in a space-separated string (no arrays needed) and checks it at the end. Exit 2 appears only for invocations that passed `--fail-on-gaps`.
