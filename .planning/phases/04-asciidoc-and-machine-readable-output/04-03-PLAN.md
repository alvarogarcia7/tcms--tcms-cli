## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ReportDocument -> file | A machine consumer parses the text and acts on it; a corrupted document must never be written |
| user strings -> JSON or YAML scalars | Ids and names come from user files |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-04-07 | Tampering | render_json, render_yaml | mitigate | Validate before returning text; YAML is validated after a parse of the text that is returned; error returns no text |
| T-04-08 | Tampering | YAML scalar typing (null, yes, 0123 read back as other types) | mitigate | Round-trip test that these come back as strings; document values are compared after re-parse |
