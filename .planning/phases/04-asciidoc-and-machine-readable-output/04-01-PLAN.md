    Public items: `pub fn escape_adoc(text: &str) -> String`, `pub fn escape_adoc_line_start(line: &str) -> String`, `pub fn render_asciidoc(model: &ReportModel) -> String`.

    Escaping design (D-02, D-06). AsciiDoc has no single backslash escape that works for every construct, so use numeric character references. Asciidoctor passes `&#NN;` through unchanged in normal (paragraph and table cell) substitution and displays the character. Do not rely on references inside literal or listing blocks: those blocks escape `&` and show the reference text. escape_adoc walks the characters once. Line feed, carriage return, tab and every other control character become one space; the pair carriage return plus line feed becomes one space. These become `&#<decimal code>;`: ampersand, less-than, greater-than, asterisk, underscore, backtick, hash, plus, caret, tilde, left and right square bracket, left and right curly brace, backslash, pipe, at sign. A colon becomes `&#58;` when it is adjacent to another colon (before or after it), when the next character is a slash, or when it directly follows NOTE, TIP, WARNING, CAUTION or IMPORTANT (case-sensitive, wherever the word occurs in the value). The start-of-line rule applies to every line, cell and paragraph start. Everything else is copied. Pipe is encoded as a reference, never as a backslash-pipe, so no separator can survive inside a value.

    Apply escape_adoc to EVERY model string written into the document: matrix id, baseline, run ids, build ids, environments, testers, generated_at, document names, requirement ids, level text, test case ids, run ids in cells. Status, outcome and column labels and fixed words are literals and are not escaped. Never build output with unescaped model strings.

    Layout. Build the string with explicit push_str and format calls in a fixed order, as render_markdown does. Constructs: title line `= ...`; section lines `== ...`; Inputs as one paragraph (not a code fence); tables as an attribute line `[cols="N",options="header"]`, a fence `|===`, one cell per line starting with `| `, and a closing fence `|===`. A cell with several cases uses the hard line break so the continuation line holds no pipe. Mirror Markdown section for section.
